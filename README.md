# Weather App

A simple weather application built with HTML, CSS, and JavaScript that fetches real-time weather data using a weather API.

## Features

- Real-time weather data
- Search by city name
- Display current temperature, humidity, wind speed, and weather conditions
- Responsive design

## Technologies Used

- **HTML** - Structure
- **CSS** - Styling
- **JavaScript** - Functionality
- **Weather API** - Data source

## How to Use

1. Clone or download the project
2. Open `index.html` in your web browser
3. Enter a city name in the search bar
4. View the current weather information for that location

## API

This app uses a weather API to fetch weather data. Make sure you have a valid API key configured.

## Installation

No installation required. Simply open the HTML file in a browser and start using the weather app.
